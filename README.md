# Краткая сводка

Telegram-бот для автоматической генерации новостных постов из Telegram-каналов-источников через Gemini AI.

## Как работает

1. Бот слушает указанные Telegram-каналы
2. Новое сообщение отправляется в Gemini AI вместе с инструкцией из `instruction.md`
3. AI генерирует пост в заданном стиле и отправляет админу на модерацию
4. Админ может: **опубликовать** / **отклонить** / **отправить на перегенерацию**

## Команды

| Команда | Описание |
|---------|----------|
| `/add <id>` | Добавить канал-источник по ID |
| `/del` | Удалить канал-источник |
| `/list` | Список каналов-источников |
| `/dict` | Показать словарь |
| `/dict_add` | Добавить запись в словарь |
| `/dict_del` | Удалить запись из словаря |
| `/dict_edit` | Редактировать запись в словаре |
| `/gen_post` | Создать пост вручную (текст + медиа) |
| `/update` | Обновить список каналов в закреплённом сообщении |
| `/set_ch_mes` | Установить закреплённое сообщение для списка каналов |
| `/get` | Отладка — получить закреплённое сообщение |

## Переменные окружения (`.env`)

- `ADMIN_ID` — ID админа (получает посты на модерацию)
- `CHANNEL_ID` — ID канала, куда публикуются одобренные посты
- `GEMINI_API_KEY` — ключ Gemini API
- `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` — данные приложения Telegram
- `telegram_bot_api` — токен бота

## Структура

- `main.py` — основной код
- `instruction.md` — инструкция для Gemini (стиль, тон, правила)
- `dictionary.json` — словарь терминов/людей
- `config.json` — список ID каналов-источников
- `temp/` — временные файлы контекста и медиа
